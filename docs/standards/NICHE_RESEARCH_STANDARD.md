# Niche Research Standard

## Mission

Research first. Build second.

Never create a tool simply because it sounds useful. Every tool must
target a real search intent with a realistic opportunity to rank.

------------------------------------------------------------------------

# Step 1: Understand Intent

Identify:

-   Primary search intent
-   Secondary search intent
-   User goal
-   Desired outcome
-   Typical user journey

Classify intent as:

-   Informational
-   Commercial
-   Transactional
-   Navigational

------------------------------------------------------------------------

# Step 2: Keyword Discovery

Produce:

-   Primary keyword
-   5--10 long tail keywords
-   Question keywords
-   Comparison keywords
-   Alternative terminology
-   Semantic entities
-   Related concepts

Requirements:

-   Low competition preferred
-   High intent preferred
-   Avoid keyword cannibalization
-   One page targets one primary intent

------------------------------------------------------------------------

# Step 3: SERP Analysis

Analyze competing pages.

Document:

-   Strengths
-   Weaknesses
-   Missing functionality
-   Missing explanations
-   Missing examples
-   UX problems

The new tool must clearly improve upon existing results.

------------------------------------------------------------------------

# Step 4: Business Value

Estimate:

-   Commercial intent
-   Advertiser value
-   Evergreen potential
-   Seasonal trends
-   Expansion opportunities

Score each from 1--10.

------------------------------------------------------------------------

# Step 5: Topic Cluster

Determine:

-   Parent category
-   Sibling tools
-   Child tools
-   Supporting guides
-   Internal linking opportunities

The page must strengthen the overall topical authority.

------------------------------------------------------------------------

# Step 6: Differentiation

Every tool should include at least one meaningful differentiator.

Examples:

-   Better UX
-   Better explanations
-   Visualizations
-   Comparison mode
-   Downloads
-   Examples
-   Faster workflow

Never create a commodity page.

------------------------------------------------------------------------

# Step 7: Build Decision

Only proceed if all are true:

-   Real search demand
-   Useful browser-based functionality
-   Fits an existing topic cluster
-   Improves on current competitors
-   Can become the best result for its query

Otherwise reject the idea and choose a stronger opportunity.
